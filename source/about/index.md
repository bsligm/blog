## 一句话

我在做的是 **AI Infra**：把裸金属算力变成稳定的模型推理服务，再把它包成 Agent 和研发能用起来的平台。现在在源策未来从 0 到 1 搭整套基础设施，重心全在具身智能的算力底座上。

## 我最近在折腾什么

- **VLA 推理加速**：给视觉—语言—动作模型的推理做延迟工程。CPU 亲和 + NUMA 拓扑联合调优，离线 A/B 下均值从 202ms 压到 193ms（-4.5%）、P95 降 5.1%；四路 CUDA Graph 预热回放稳定在 ~120ms。每一次调优都留可复现的基准，不靠「感觉变快了」。
- **GPU 切分与资源形态**：PVE 上跑 L40S 的 vGPU 与 RTX PRO 6000 的 MIG 切分，配合 CPU 亲和、VFIO 直通与共享存储，把数据中心级 GPU 切成研发能按团队、按任务粒度领取的推理资源。
- **多 Agent 接入**：从 DGX Spark 单卡 256K 上下文，到 vLLM 推理服务对接 LiteLLM，统一给 Codex、Claude Code 等主流 Agent 客户端供模型。并发策略、多模态图片识别、协议兼容性调试，都是踩出来的。
- **身份与零信任**：设计「飞书（组织主数据）→ 飞连（口令权威）→ AD（本地资源权限）」的职责链，Entra ID 云身份在下游规划。核心是把可信身份、权限校验和远程接入拧成一条企业级底座，而不是各管各的。
