## 我怎么用 Agent

我想做的 AI Native，是让 Agent 能接进已有的运维流程。现在交给它比较多的是查状态、读日志和整理变更前后的结果。比如查一台服务器为什么连不上，先看 JumpServer 里的授权和会话。要往系统里查，就用那台机器的账号和已经授权的入口。改资产、开权限或重启服务时，有人确认范围，工具按实际权限执行，结束后再去查对象或发一条业务请求。

固定的检查适合写成脚本，Agent 可以顺着异常挑下一条证据。遇到同类故障，再从知识库找以前看过的日志和处理结果。家里推理服务掉线时，这几步已经各自用过。接下来想做的是让告警先触发一次只读调查，把查到的东西交给人决定要不要恢复服务。{% post_link AI-Native的五个维度从接管到自运转 "家里的 Agent 运维试验" %} · {% post_link 把家里的算力全掏出来WeKnora模型保障实录 "WeKnora 本地模型路由" %}
