我做 AI Infra，也负责把平台交到研发手上。从早期的企业 IT、存储和虚拟化，到现在为具身智能研发搭基础设施，我做得最多的是把几套各自能跑的系统接成一条可用的链路，让团队能拿到算力、复现实验、验证性能并在变更出问题时恢复。

这十来年做过从零建设，也做过现场交付。现在我更关心一个具体的问题。模型、Agent 和业务脚本接进来以后，谁给它们发权限，出问题能看到哪一步，做完又该去哪里核对结果？

## 我在尝试什么

我希望 Agent 能参与日常工程。先给它结构化的状态、受限的工具和可回读的执行结果。固定步骤放进脚本，让 Agent 调查异常、整理证据并给出处置建议。涉及权限和生产变更时，审批和最终验收由人负责。

我目前按五件事看这套系统做到哪一步。工具能否被 Agent 稳定调用，数据写入时是否带上来源和口径，事件能否触发有边界的协作，经验能否回到知识库，以及人能否用自然语言描述任务并复核结果。已在用的部分和仍需验证的自动化都写在 {% post_link AI-Native的五个维度从接管到自运转 "AI Native 实践记录" %} 里。
